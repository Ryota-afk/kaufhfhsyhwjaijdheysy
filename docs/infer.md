## 最初の候補

- **上位206構築に出る種族（110種族）**：出てきた型をそのまま候補にします。同じ型は重みを足します。特性が空の個体は、その種族の特性に等分します。
- **上位構築にない型（「それ以外」）**：「それ以外」を1回分として数えます（上位構築に n 回出る種族なら 1/(n+1)）。
  - 例：ガブリアス（100回）は約1%、1回だけの種族は50%。
  - 上位構築に出ない種族（チャンピオンズで選べる293種族のうち183種族）は、「それ以外」だけになります。
- **「それ以外」の中身**：Showdown のチャンピオンズの型データ（data/random-battles/champions/sets.json）から、役割（速いアタッカー、耐久型など）ごとの技の候補と特性を取ります。
  - 持ち物・性格・能力ポイントは、上位構築で同じ組み方の型（例：「すばやさ」と「こうげき」に振った型）がよく使うものを、出てきた割合で当てます。
  - メガストーンは、上位構築で「メガシンカできる種族がメガストーンを持っていた割合」（0.691）で当てます。

**ここまでの割合は、データからの推定です。仕組みの事実ではありません。** 対戦記録がたまったら（段階6）、記録で置き換えていきます。

## 見えた情報（手がかり）と、その確率

| 手がかり | 候補ごとの確率 |
|---|---|
| 技 | 上位構築の型：見えた技を全部持っていれば1、そうでなければ0。「それ以外」：技の候補 n 個から4つ選んで、見えた技 k 個を全部含む確率 C(n−k, 4−k)/C(n, 4) |
| 持ち物・特性 | 一致すれば1、しなければ0。「持ち物が○○ではない」（例：ターンの終わりにたべのこしで回復しなかった）も使える |
| 行動の順番 | Showdown の行動の順番の決め方（優先度、すばやさ、トリックルーム、こだわりスカーフなど）で計算。同じ素早さは1/2。せんせいのツメは1/5で先に動く |
| 相手が受けたダメージ（%） | 相手の見えるHPは「100×残りHP÷最大HPの切り捨て、残っていれば最低1」（Showdown の champions と同じ）。受ける前の%に当たるHPの値を等しくありうるとし、乱数16通りのダメージで「受けた後の%」になる割合 |
| こちらが受けたダメージ（実数） | 乱数16通りのダメージのうち、HPの減り方が一致する割合 |

ダメージは、Showdown の技の処理を次の順に通してから `getDamage` で計算します。

1. ターンの初めの処理
2. タイプ・技の変化
3. 技を出す前の処理
4. 当たる直前の処理

乱数ごとに盤面を複製し、きのみを食べるなどの変化が次の計算に残らないようにしています。

## 確かめた結果

| 確かめ | 結果 | 道具 |
|---|---|---|
| ダメージの計算が、実際に打った結果と合うか | 519 / 519、734 / 734 回一致（相手が先に動いて状態が変わった回、きあいのタスキ・がんじょう・ばけのかわ・ふうせんの回は対象外） | `npx tsx tools/infer/damage-check.ts` |
| 行動の順番の計算が、実際に打った順番と合うか | 確率0か1の回は 1917 / 1917 回当たった。同じ素早さの30回は相手が先が0.63（期待0.5、回数が少なく誤差の範囲） | `npx tsx tools/infer/order-check.ts` |
| 用意した例（技・持ち物・特性・素早さ・ダメージ・控え） | テスト8件すべて合格。期待値は本体とは別の方法で計算した（ダメージは実際に1500回打った割合と比べた） | `npm test`（test/infer.test.ts） |

照合で見つけて直したずれ：

- 計算の前にターンの初めの処理を通していなかった。ねつこうかんでやけどが治る前の、半分の攻撃で計算していた。
- 技を出す前の処理を通していなかった。エレクトロビームの「とくこう」アップが入っていなかった。

## 弱点・残っていること

- 連続技は1発分のダメージしか計算しません。合計のダメージを手がかりにするのは段階4以降です。
- オボンのみなど、ダメージの直後の回復が入った後の%は、そのままでは手がかりに使えません。回復は持ち物の手がかりとして別に入れます。
- 「それ以外」の型の組み方（役割→能力ポイントの形の対応）は、私が決めた対応です。例えば耐久型の役割に「ずぶとい」（こうげき↓）が混ざるなど、物理アタッカーに合わない性格も候補に入ります。
- 控えの推定で、選出の記事の「基本選出が何割か」（freq）は文で書かれていて数にできないため、1件を同じ重みにしています。
- まだ画面からは使えません。対戦中の入力画面は段階4で作ります。
